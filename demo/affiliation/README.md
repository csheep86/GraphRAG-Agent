# `demo/affiliation` —— M4 四源对齐**合成**语料

> ⚠️ **本目录全部为合成数据**：公司名 / 税号 / 地址 / 金额 / 日期均为**构造值**，
> **不含任何真实客户信息**，也**不来自**任何真实业务系统。仅用于
> `specs/m4-affiliation-detection.md` §3 验收 1（四源主体对齐成功率 ≥ 0.95）的判据。
> （沿用 `dev-doc-status.md` **R9** 的语料标注纪律：合成数据必须自证是合成的。）

## 1. 文件与 schema

| 文件 | 角色 | 行数 |
|---|---|---|
| `suppliers.csv` | 供应商主数据 = **canonical 主体**（对齐目标） | 20 |
| `invoices.csv` | 发票（待对齐源） | 60 |
| `vouchers.csv` | 凭证（待对齐源） | 30 |
| `contracts.csv` | 合同（**S9.12 增补**：三方金额比对的第三方） | 8 |
| `shareholders.csv` | 持股（**S9.12 增补**：`cycle` 的输入） | 10 |

列名 / 必填 / 校验 / 对齐口径**唯一真源 = `specs/m4-affiliation-detection.md` §4.6**
（本文件不复述，避免第二真源）。

> ⚠️ **`contracts.csv` 是 PDF 合同的合成替身**：spec §1.1 的合同是 **PDF**（走 M2 抽取链路）。
> 本文件只作为「三方金额等价输入」用于验证**算法判据**，**不是**在验证 PDF 抽取——
> 该偏离已登记于 spec §4.6.6。真机合同的汇合点 = `:Contract` 节点属性（形状一致）。

|---|---|---|
| `invoices.csv` `FP2026-0005` | 税号空 + 名称 / 地址都不在主数据 | `tax_id_missing` |

| `invoices.csv` `FP2026-0023` | 税号空 + 名称「北京恒信达科技公司」规范化后命中 **S001 / S002 两家** | `multiple_candidates` |
| `vouchers.csv` `PZ2026-0008` | **S9.13 改名**：名称「天津市滨海华元机械有限公司」（比 S011 多一个"市"字）+ **税号保留** | `name_mismatch` |

> **S9.13 为什么改这两行的名字（不改行数）**：批次 C3 的实体消解需要真机可核对的别名样本，
> 而"增行"会把 S9.11 的判据（总数 90 / 未对齐 4 / 0.9556）推翻 ⇒ 只能改名。
> 两条**一清税号、一留税号**，恰好把 N1（税号冲突 ⇒ 封顶 0.85，**永不自动合并**）的
> **两个方向**都做成真机样本：前者走通 `auto_merged`，后者验证"该挡的挡得住"。
> 详见 `changes/archive/2026-09-29-Sprint9.13/proposal.md` §2.1 与 `specs/m2-extract-kg.md` §4.5.1。

**为什么必须植入**：只放"必然对齐"的数据，成功率恒为 1.0——那不是验收，是自证。
刻意留 4 条 ⇒ 预期对齐率 **86 / 90 = 95.56%**（≥ 0.95，且**有余量**，
不需要靠调阈值凑数）。

## 4. 用法（工作目录 = `backend/`）

```bash
uv run python scripts/ingest_affiliation_sources.py --dry-run  # 只解析 + 对齐，不写库
uv run python scripts/ingest_affiliation_sources.py            # 摄入 + 对齐 + 落 unaligned_subjects
```

- 写入**独立 org / 独立 `kg_version`**（`affiliation-demo-v1`），
  **不碰**演示库的 `attendance-demo-v1`（无不可逆代价）；
- 确定性、**不经 LLM**（结构化数据用 LLM 抽取是错配）⇒ 全程 ¥0。

## 5. 不做什么

- **不是**演示语料：演示路径仍是 `demo/attendance/`（考勤域），本目录**不参与演示**；
- **不含**合同 PDF——合同侧**真机**走 M2 抽取链路，`contracts.csv` 只是三方金额的
  **合成替身**（见上文 ⚠️）；
- **规模不足以做场景准入**（spec §3 验收 6 要 200 合同 / 500 发票 / 100 凭证 / 20 组植入）：
  本目录只有 8 合同 / 60 发票 / 30 凭证 / 9 组 ⇒ **不宣称**召回 ≥ 0.80 / 误报 ≤ 0.15，
  该判据维持未做（缺口 **S13**）。
