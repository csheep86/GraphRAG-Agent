## 1. 归因：**先验先走**（避免"一律放宽拒答判定"这条假绿）

一条提问被拒答，可能卡在互不相同的好几层；**在哪一层决定了修什么**：

| 层 | 卡住的含义 | 该怎么修 |
|---|---|---|
| L1 | 目标 chunk 不在 `kg_version` 内 | 题集与语料不同源 ⇒ **改题集**，不许改检索 |
| L2 | 500 采样实体 → `MENTIONS` 捞不到 | 结构性窗口（R22 已登记）⇒ 登记规模风险 |
| L3 | 图候选 ∪ 字面量召回也没覆盖 | 查 P6-N 的 `LexicalIndex` |
| L4 | 在候选里但没进最终 32 条 | 选片规则（P6-J 词面重排那一层） |
| L5 | 进了 32 条仍拒答 | LLM 归因闸门 ⇒ **必须 live**，非确定性 |
