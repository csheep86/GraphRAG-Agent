## 1. 裁决条款（**照抄 L10-A8，不得自行放宽**）

1. **扩标、不改 spec**：200 合同 / 500 发票 / 100 凭证 / **20 组植入**（五类 × 每类 ≥4 组）；
2. **补统计口径**：报告输出 `n` + 95% 单侧置信界，**判定用界**（C2-a 用**下界**、C2-b 用**上界**）；spec 的点估计门槛保留（命中 <16 组即 FAIL），但要**宣称达标还须界达标**；
3. **gold 植入必须有文本体现**：现有 9 组是"从 CSV 结构化字段推导"的 ⇒ 算法读同一批字段 ⇒ 命中是必然 ⇒ 测的是"推导一致性"，**不是**"发现隐藏关联"；
4. **语料分层**：**L1 算法层**（合成语料）判 C2-a / C2-b；**L2 端到端**（真机文档走 M2 抽取）小样本**只留证**；报告带 `corpus_layer`；
5. **G5 声明**：L1 须写明"仅验证算法层，未经端到端验证"。

**基准值（裁决给定，用作单测断言）**：19/20 下界 ≈**0.82** ✓ ／ 18/20 ≈**0.75** ✗ ／ 16/20 ≈**0.62** ✗ ／ 0/20 误报上界 ≈**0.139** ✓ ／ 1/20 ≈**0.18** ✗。

## 3. Non-goals（本批**不做**）

1. ❌ **不宣称达标**：本批只把「**能判**」造出来（语料 + 统计口径）。是否达标由**实测值 + 界**说话；若 v2 上误报 >0（上界 >0.15）⇒ 如实记 FAIL，**不调阈值、不删 gold 组**；
2. ❌ **不改 spec 规模**（200/500/100/20 一个都不动），也不改 `specs/m4-affiliation-detection.md`；
3. ❌ **不做 L2 端到端**（真机文档走 M2 抽取 ⇒ 需真机 + 抽取链路，成本高），本批只把 `corpus_layer=L1` 写进报告与 gold，L2 另批；
4. ❌ **不做 A1**（向量基线 / 双侧判分 / 反向守卫）——与 C1 图谱增益相关，另批；
5. ❌ **不做 A6+L8 的含拒答档**（`runner` 两处 `include_refused`）与拒答误伤判据——另批；
6. ❌ **不改检测算法**（`graphs.py` 五类 Cypher）、不动阈值、不改 `metrics.py` 的匹配键；
7. ❌ 不动契约 / ADR 原文（ADR 按 R5 不改）；不动租户隔离代码。

## 4. 需要**显式登记**的两处自由裁量

1. **suppliers 规模 spec 未定**（spec 只定 200/500/100/20）⇒ 本批取 **120 家**。理由：① 500 张发票要分摊到主体上，主体太少会让"随机主体共享地址/电话"的碰撞概率上升 ⇒ **污染误报判据**；② 20 组植入涉及约 8+8+8+10+12 个主体，120 家留足噪声空间。
2. **对齐率**：v2 语料**刻意全对齐**（100%）。理由：C2-a / C2-b 判的是**召回 / 误报**，而"未对齐 ⇒ 无 `source_entity_ids` ⇒ **无证据即丢弃**（`affiliation.py:193-202`）"会让召回判据被对齐噪声污染 ⇒ 对齐率判据（spec 验收 1）**仍由 v1 手工语料承担**，v2 不宣称它。
