## 0. 一句话

**"进方向"的第一步不是写代码，是把三个方向放在同一把尺子上量一遍** —— R22 明文禁止凭猜测定案，
而 P6-L 刚给出的 **35.93%** 正好提供了那把尺子。本批写一个 ¥0 探针，用**机械构造的查询集**
把 ①字面量召回 / ②实体链接召回 拉到同一组查询上比"目标片段能不能进 top-32"；
③向量召回**只给书面成本说明**（需嵌入模型 + 向量库 ⇒ 引入依赖，与既有 Non-goals 第 4 条冲突）。

## 1. 为什么**本批不实现**

| 选项 | 问题 |
|---|---|
| 直接实现 ①（最像赢家） | **违反 R22 明文纪律**："勿凭猜测定案"。便宜 ≠ 赢，赢面要用数说话 |
| 比选 + 同批实现 | 落地要改 `fetch_evidence_chunks` 的**候选构造层**（生产链路）⇒ 会动到 attendance 40 题那条链路。按 D2 第④条，动 40 题 ⇒ **两侧 40×2 全量重判**，而**判分口径用户已裁决后置** ⇒ 单独成批（P6-N）更可控，本批不混 |
| **只比选（本批）** | ¥0、不动链路、不需判分、当天出结论 ⇒ 且它正是落地前唯一缺的那份依据 |

⇒ 本批产出的是**一张比选表 + 一个明确方向结论**；落地（P6-N）拿着这张表开工，
不必再回头问"该做哪个"。

## 2. 探针设计（**全机械量，零判分**）

### 2.1 查询集：机械构造，不是人工出题

`affiliation-demo-v2` 的 `Voucher` 实体带 `trade_ref` 属性，真机实测：

```
MATCH (c:Chunk{kg_version:'affiliation-demo-v2'}) WHERE c.text CONTAINS 'TR-0001' ⇒ 3 条
含 'TR-' 的 chunk 共 300 条 = 100 个键 × 3 条
```

⇒ **查询集 = 100 个 `TR-00xx`**；**gold = 文本含该键的那 3 条 chunk**。
gold **由语料机械确定**（不需要人判断"答案对不对"）⇒ 满足 D2「判据必须是机械量」。

### 2.2 三档候选构造（同一组 100 查询、同一条选片规则）

| 档 | 候选怎么来 | 对应 R22 的 |
|---|---|---|
| **B 基线（现状）** | 500 采样实体 → `MENTIONS` → chunk（P6-L 实测 **355** 条） | 现状：问句全程不参与检索 |
| **① 字面量召回** | `c.text CONTAINS $key` ⇒ chunk | 方向①（BM25 / 关键词倒排，¥0、无外部依赖） |
| **② 实体链接召回** | `Entity.trade_ref = $key` → `MENTIONS` → chunk（**全图匹配，不受 500 采样限制**） | 方向②（问句抽实体 → 图上定位） |

三档都过**同一条选片规则**（P6-E 的"每文档保底 + 组内 `(-mentions, char_start)`"，取 32 条）
⇒ 唯一变量是"候选从哪来"，比的就是它。

### 2.3 出什么数

1. **gold 命中率** = gold 的 3 条里，有几条进了最终 32 条（逐查询 + 均值）
2. **候选池大小**（该档候选了几条）
3. **字符成本**（32 条合计字符数 —— 防止"靠砸字符换召回"，这正是 R22 处置里点名的坑）

## 5. 冻结的 Non-goals（10 条）

1. **不落地任何召回**、不改 `fetch_evidence_chunks` / `select_evidence_chunks` / agents 链路
2. **不判分**、不动 attendance 40 题、不出 C1
3. 不改三个配额 `_GRAPH_NODE_LIMIT` / `_EVIDENCE_CHUNK_INDEX_LIMIT` / `_EVIDENCE_CHUNK_LIMIT`
4. **不引入第三方依赖**、不装向量库 / embedding（方向③ 只做书面说明）
5. 不加 `settings.*`、不改契约（`export_openapi.py --check` 必须零 diff）、不加表
6. 不改语料、不改生成器 seed
7. 不改 P6-K 的哨兵逻辑、不改 P6-L 的诊断脚本（本批**新增**一个并列脚本）
8. 不建倒排索引 / 全文索引（真要落地时再定；本批只用 Cypher 等价表达验证**召回能力**本身）
9. **不下"开放性提问也适用"的结论** —— M-D5：本批只测键级查询
10. 不顺手修 H6 403 / 入图器自检 / P7-B / G-12 / MANIFEST / CI 上 5 条恒定 skip 的盲区
