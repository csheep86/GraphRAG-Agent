## 4. 版本接线：本批发现的最大隐患

`runner.py` 里有 **8 处**写死的 `dataset_version="controlled-qset-v3"`。
这不是「文档没同步」层面的小事 —— 报告里的 `dataset_version` 字段是**两次运行可比**的依据，
题解换成 v4 而它写 v3，**报告就会撒谎**。本批全部改为 v4（实测报告已 readout
`provenance.dataset_version = controlled-qset-v4` ✅，且仓库内 `controlled-qset-v3` 残留 **0 处**）。

同时发现**题数有 3 处写死副本**（`test_eval_qset.py` 的 `== 14` / `test_eval_qset_parity.py`
的 `== 14` / `test_evaluation_dataset.py` 的 `== 14`）。扩容时前两处改了、第三处没改 ⇒ **测试真的红了**
—— 那是哨兵该响的时候，但更该做的是**让它不再需要人改**：

> 三处现已全部改为**从 MANIFEST 的 v4 条目读题数与配额** ⇒ 题数的单一真源只剩一处。

同理新增 `test_qset_sensitivity_stays_within_budget`：**灵敏度 ≤ 2.5pp 变成机器判据**
⇒ 以后若有人为了省事裁题，这条会红。
