# Sprint 10.5 提案：知识时效 L2-② / ③ 收尾（失效视觉语义 + 全生命周期 as-of）

## 1. 要做什么

把 10.4 登记为「未做」的 L2 两块补上：

- **② 失效视觉语义**：答案所依据的路径上若含 `valid_to` 已过期的边，前端把它画成**虚线置灰**，不再与有效边同色。
- **③ 全生命周期 as-of**：同一个问题按不同时点（2025 年中 / 2026 年当下）作答，答案依据**跟着时点变**。

前置是「图上得先真有失效边」——这是本批次 90% 的工作，见 `00-recon.md`。

## 2. 判据（可机械验收，不许用「看起来对」结案）

| # | 判据 | 怎么验 |
|---|---|---|
| J1 | 演示库出现 `valid_to` 非空的关系，**且**其值的出处能在 2025 版文档正文里指行数 | Neo4j 计数 + 反查条款 |
| J2 | 存在 `_temporal_verdict = inconsistent` 的链（10.4 探针是 0） | `probe_l2_path_temporal.py` 重跑 |
| J3 | ② 视觉：含失效边的路径在用量 / 问答的答案里呈现时，前端把 ``valid_to`` 已过期的边渲染为**虚线置灰**（不再与有效边同色，口径见 §1 ②），且**不影响** ``effective`` 边的渲染 | 前端 + 截图/断言 |
| J4 | ③ as-of：同一问题两时点答案不同，且差异点正是 2025/2026 那一条真实的制度差异 | 真实 LLM 两组问答 |

## 3. 顺序（不可调换）

```
写 2025 版双文档（差异只一处 + 明写失效日期）
  → generate_corpus.py 产物重生成（零改动）
  → 入库 + 重建图谱（真实 LLM 抽取）
  → 【闸门 G1：¥0 探针】valid_to 是否非空？
        否 ⇒ 停止，报告（禁止脚本手写 valid_to）
        是 ⇒ 继续
  → 【闸门 G2：¥0 探针】inconsistent 是否由 0 变非零？
  → ② 前端虚线
  → ③ as-of 双时点问答
  → 【闸门 G3】受控题集回归
  → 收尾
```

**为什么 gate 先行**：② 和 ③ 都要花钱、都要改前端/ Prompt。图上没有失效边就动手，
做出来的虚线分支与 as-of 分支**永远走不到**，等于交付一段没有消费者的代码（CODEBUDDY.md：无消费者的东西不提交）。

4. **不动** `relation_expiry_policies`（它与本域无关，见 recon 第 1 节）。
5. **不碰** R22（检索相关性）——独立议题。
