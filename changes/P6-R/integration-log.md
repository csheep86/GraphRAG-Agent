## 4. 落地 O1（用户裁决）

```python
# backend/app/services/providers/llm.py —— build_chat_model()
return ChatOpenAI(
    ...
    # P6-R 裁决 O1：钉 0 ⇒ 采样确定化（问答 / 抽取 / 本体建议三条路径一并生效）。
```

**裁决要点（D1 / D2）**：

**它不是放宽判定（A6 第 2 条 / Non-goal 1）**：`no_grounded_evidence` 判定**一行未改**，

## 6. 连带面实测（T5 · 选 O1 的必答项）

### 6.1 抽取侧：默认采样下**入图产物本身就不可复现**

新增探针 `scripts/probe_p6r_extraction_drift.py`（固定文本、**图外**跑、不写库 ⇒ 不污染演示图）：

| 轮次 | 采样 | run 1 | run 2 | `identical_across_runs` |
|---|---|---|---|---|
| **before** | 默认 | 14 实体 / 7 关系（`49f19bf6…`） | **19 实体 / 8 关系**（`4764fe7b…`） | **false** |
| **after** | T=0 | 12 实体 / 9 关系（`269b67f3…`） | **12 实体 / 9 关系**（`269b67f3…`） | **true** |

> **这是本批最有价值的新事实**：抖动**不只是**问答侧那条判据的读数问题——
> 同一份固定文本连跑两次，抽取出的实体数是 **14 vs 19**，关系 **7 vs 8**，**逐位不同**。
> 钉 T=0 后两次**完全逐位一致** ⇒ 入图产物由**不可复现**变为**可复现**。
>
> 反过来说：**改动后的抽取产物（12 / 9）与改动前的两次（14 / 7、19 / 8）都不同** ——
> 这是必然的（任何一次采样结果都不会与另一次相同），**关键改善是可复现，不是"更接近某个真值"**。
