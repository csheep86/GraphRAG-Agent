## 2. 契约变更（`contracts/openapi.yaml`）

**路径 5 → 8**（新增 3 条）：

| 路径 | 说明 |
|---|---|

| 错误码 | 语义 | 来源 |
|---|---|---|
| `KG_TENANT_LEAK` | 跨租户子图泄漏检测到 → 403（**数据质量事故不得伪装为正常结论**） | 批次 B / ADR-0003 §4 |
| `ENTITY_NOT_FOUND` | 实体不存在或不属于当前 active kg_version → 404（**与跨租户 403 严格区分**） | 批次 C |

## 6. 已知限制与降级登记（v1.2.0 待办）

### 6.1 E1 / E2 数据质量：**`unresolved`**（按 §4.4 降级预案第 3 条收口）

**两项均未产出数字，登记为 `unresolved`——维持现状，不顺延到下一批次。**

| 项 | 要求 | 实际 | 结论 |
|---|---|---|---|
| E1 孤立节点率 | 财务指标类实体中「无任何边」的占比 | **未产出** | `unresolved` |
| E2 命名可疑率 | 实体名不符预期的占比 | **未产出** | `unresolved` |

**根因（非托辞）**：批次 B 落地的 `LangextractClient` 是**默认 mockable** 实现——`_default_extract_chunk` 为基于正则的占位抽取器，**真实 LLM 调用留 `_evaluate_client_call_llm` 占位**（受 `extraction_provider` 切换键约束，未实现别档显式报错）。该设计保证 CI / 单测零外部依赖，但产物**不反映真实 LangExtract 的抽取质量**；在其上统计出的数字是"正则抽取器的性质"而非"E1/E2 的性质"，**拿它登记等于用假数据冒充结论**。

**后续归属**：按计划 §10，E1/E2 为**条件吸收 → Sprint 13**——若 C2 实验结论为「召回 < 0.80」，E2 的 Prompt 抽取规范重设计升为 Sprint 13 阻塞项。抽取模板 `prompts/kg_extraction_v1.md` 已就位，接入真实档位后**无需重新设计模板**即可产出这两个数字。

### 6.2 MinerU 真实云调用未在本机执行（§4.4 降级预案第 1 条）

本地 `.env` 未配置 `MINERU_TOKEN`，**真实 PDF 云调用未在本机跑通**。以 `httpx.MockTransport` 全流程单测覆盖（含 running→done 轮询、failed、超时、缺产物路径），链路不静默；真实调用留待注入 token 后的手工验收。

## 7. 升级与回滚

### 7.1 ⚠️ 破坏性变更：环境变量改名（必读）

批次 A2 的 provider 抽象将 `DEEPSEEK_*` 收敛为 `LLM_*`。**升级后旧名残留不会报错但也不会生效**（`Settings` 为 `extra="ignore"`），会导致 API key 读空 → Agent 端点 501（显式失败，不静默降级）。

| 旧（v1.0.0） | 新（v1.1.0） | 默认值 |
|---|---|---|
| `DEEPSEEK_API_KEY` | `LLM_API_KEY` | 空 |
| `DEEPSEEK_BASE_URL` | `LLM_BASE_URL` | `https://api.deepseek.com` |
| `DEEPSEEK_MODEL` | `LLM_MODEL` | `deepseek-chat` |
| `DEEPSEEK_REQUEST_TIMEOUT_SECONDS` | `LLM_REQUEST_TIMEOUT_SECONDS` | 60 |
| —（新增） | `LLM_PROVIDER` | `openai_compatible` |
| —（新增） | `PARSER_PROVIDER` | `mineru_cloud` |
| —（新增） | `PIPELINE_STAGES` | 四阶段全启 |

**迁移动作**：本地 `.env` 按上表改名即可，**值语义不变**（`LLM_BASE_URL` 仍指向 DeepSeek）。`.env.example` 已同步。

### 7.2 数据库：dev 库需重建（无迁移脚本）

`documents` 表新增 8 个预留列 + 5 个阶段列，`kg_versions` 为新增表。项目尚未引入 Alembic，**SQLite 存量库无 ALTER 迁移**：

```bash
rm backend/dev.db    # 下次启动 lifespan 自动 Base.metadata.create_all 重建
```

CI / 测试不受影响（`conftest` 每次用临时目录新建库）。**v1.1.0 内无生产部署**，生产 PG 迁移在引入 Alembic 时统一补。

### 7.3 回滚

- **优先**：`git revert -m 1 <merge-commit>`（保留历史）；
- **未推送时**：`git reset --hard v1.0.0`；
- **注意**：回滚后需**回退 §7.1 的环境变量改名**，并将 `app_version` 改回 `1.0.0`（否则接缝门禁版本闸门仍按 1.1.0 上闸）。
