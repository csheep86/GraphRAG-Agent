## 1. 重排原则（**按需求，不按旧编号**）

1. **签单优先**：能解锁签单的排最前（A 组交付骨架 + SSO）。
   ⚠️ **2026-10-01 时效注**：用户确认当前为**研发阶段、无客户** ⇒ 该原则**暂不适用**，
   顺序改按**风险优先**（越权 / 隔离优先于 SSO），见 §8.2 开头顺序说明；一旦有客户进场，本条重新生效。
2. **基础设施不晚于功能**：PG 切换**尽早**——每多一天 SQLite 开发，就多累积一批方言债（`Uuid` 无连字符格式已踩过一次）。
3. **依赖驱动**：有前置关系的严格串行；无依赖的并行。
4. **每条需求配护栏**：阶段出口 = 该阶段的护栏**在 CI 上绿**。缺护栏的需求**不宣称完成**。
5. **不单独为"转 PG"开阶段**：它是 P1 的一部分，随 G-8 落地。
