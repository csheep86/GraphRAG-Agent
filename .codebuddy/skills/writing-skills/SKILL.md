# 技能名称：writing-skills（编写新技能）

## 用途
按统一规范在 `.codebuddy/skills/<技能名>/SKILL.md` 创建高质量技能，保证技能职责单一、触发明确、步骤可执行、输出可验收。

## 触发条件
- 用户要求新增或改进一个技能。
- 发现某类工作被反复执行但没有对应技能沉淀。

## 执行步骤
1. **明确职责**：用一句话说清技能做什么；说不清就拆成多个技能。
2. **命名**：目录名即技能名，使用小写连字符动词短语（如 `dispatching-parallel-agents`），与既有 13 个技能风格一致。
3. **写 frontmatter**：`name`（与目录名一致）+ `description`（一句话，含触发场景，让模型能据此判断何时加载）。
4. **写正文五要素**：技能名称、用途、触发条件、执行步骤、输出格式。
5. **控制篇幅**：正文聚焦流程与规范，领域知识引用现有文件（如 `CODEBUDDY.md`、rules）而不复制粘贴。
6. **自查**：
   - 触发条件是否与其他技能重叠？（重叠则合并或明确边界）
   - 执行步骤是否可直接照做（无歧义、有顺序）？
   - 输出格式是否可验收？
7. **登记**：若新技能属于工作流的一环，更新 `using-superpowers/SKILL.md` 的技能地图。

## 输出格式
一个完整 SKILL.md 文件：
- frontmatter（name / description）
- 五个章节：技能名称、用途、触发条件、执行步骤、输出格式
- 必要时附"典型组合"或"注意事项"小节
