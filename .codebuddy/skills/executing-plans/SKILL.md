# 技能名称：executing-plans（执行计划）

## 用途
按计划逐项执行开发任务，保持进度可追踪、过程可回溯，并在每步完成时立即验证，避免"一口气写完再发现问题"。

## 触发条件
- 存在已确认的实施计划（`changes/<id>/tasks.md` 或等价 checklist）。
- 用户要求"开始执行 / 继续 / 做下一项任务"。

## 执行步骤
1. **定位进度**：读取计划，找到第一个未勾选任务；如果是首次执行，先向用户复述计划摘要与起始点。
2. **执行单任务**：只做当前任务，不越界做后续任务；遵守角色隔离（当前任务属于哪个角色就只能改对应目录）。
3. **立即验证**：任务完成后运行其声明的验证手段（测试 / lint / 构建契约检查），失败先修复再继续。
4. **勾选并提交**：验证通过后勾选计划中的对应项，按 Conventional Commits 提交（仅当用户要求提交时）。
5. **同步契约**：若任务改变了接口，先回到计划确认契约同步任务是否已完成，未完成则停下报告（契约同步铁律）。
6. **遇到偏差**：计划与实际情况不符时，停止执行，报告偏差并建议修订计划，不擅自改方向。
7. **循环**：回到步骤 1，直至全部任务完成。

## 输出格式
- 每完成一个任务：一行进度汇报（任务号、结果、验证输出摘要）
- 全部完成时：**执行总结**（完成 / 跳过 / 失败任务数、验证结果、遗留问题）
