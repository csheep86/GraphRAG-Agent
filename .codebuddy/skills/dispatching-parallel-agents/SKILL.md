# 技能名称：dispatching-parallel-agents（并行代理派发）

## 用途
识别工作中可并行的部分，同时派发多个代理执行，用并发换时间；同时保证并行任务互不冲突、结果可合并。

## 触发条件
- 存在多个互不依赖的子任务（如同时探索前后端代码、批量处理多个文件、多模块独立调研）。
- 单个串行执行明显浪费时间，且任务间无共享状态。

## 执行步骤
1. **识别并行性**：列出全部子任务，检查两两之间是否存在文件写冲突、顺序依赖或共享状态。
2. **划分批次**：无冲突的任务放同一批并行；有依赖的按拓扑排序分批。
3. **构造派发提示**：每个代理的提示必须自包含（不依赖其他代理的中间结果），写明：目标、只读还是可写、涉及路径、期望输出格式。
4. **并行派发**：同一批次内一次性发出全部 Task 调用。
5. **结果合并**：收齐本批结果后统一核对；发现冲突（两个代理改了同一文件）时，以后完成者为准重新验证或回滚重做。
6. **禁止并行的情形**：修改同一文件、共享 Git 状态、需要彼此输出作为输入——这些必须串行。

## 输出格式
- **并行性分析**：子任务矩阵（任务 × 冲突关系）
- **批次计划**：每批包含的代理任务与派发提示摘要
- **合并结果**：各代理输出汇总 + 冲突处理记录
